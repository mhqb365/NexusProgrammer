# Security Policy

## Supported Versions

The project is experimental and currently supports the `main` branch only.

## Reporting a Vulnerability

Please open a private report through GitHub security advisories if available, or
contact the maintainer before publishing details.

Include:

- A concise description of the issue.
- The affected commit or release.
- Steps to reproduce.
- Whether the issue can cause device access, data loss, chip erase/write, or
unexpected host command execution.

Please do not include private dumps, firmware images, or sensitive captures in a
public issue.
